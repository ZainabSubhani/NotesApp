Category palettes — two-tier, non-overlapping

Default categories are seeded once at first launch and are locked (cannot be renamed or deleted). Users add their own with the + chip; custom categories draw from a separate palette so they can never visually collide with a default one. Color belongs to the category, applied consistently everywhere it appears.
